# Programmer Mixology 1.2.0 / 程序员调酒台

`TASTE × RULES × AI  /  MIT  /  LOCAL FIRST`

## English
TIMER Mixing Desk is now **Programmer Mixology / 程序员调酒台**. New profiles, the installer and README default to English; Chinese remains selectable and existing valid language preferences are preserved.

- Bilingual seven-panel pixel UI, per-drink ASCII artwork and archive icons, taste/sensory controls, preparation queue and `.timermix` snapshots.
- 300 base recipes and the enabled 96-drink Xiaodong notebook DLC are bundled together. Authorized original notes and supplied personal recipes are included in source, with editorial estimates separate from original records.
- Illustrated documentation, architecture guide, MIT license and a fork/branch/pull-request contribution workflow.
- The long-term aim connects AI, nutrition data, deterministic calculation and real human taste feedback for recipe exploration. Comprehensive nutritional optimization and experimentally calibrated prediction are research goals, not completed features.
- Existing application/data/archive identities remain compatible. No user databases, account credentials, model weights or order histories are distributed.

Download the real Windows x64 installer and verify `SHA256SUMS.txt`. The installer is unsigned and requires an existing WebView2 runtime. Classic mode works without a model.

Validation: 271 frontend tests, 151 Rust tests, 44 reference tests, 8 export safeguards, 9 native UI groups, 20 installer-helper checks and 25 actual installer lifecycle checks passed. See [build report](1.2.0-BUILD_REPORT.md) for exact scope, earlier failures and remaining platform boundaries.

The Chinese documentation includes its own fully translated architecture diagram. Both language versions include the original Xiaodong notebook and authorized personal-recipe source links.

## 中文
TIMER 调酒台现更名为 **程序员调酒台**，英文项目名 **Programmer Mixology**。

- 中英双语、固定七区像素界面、逐杯 ASCII 画像与图标、五味/七维控制、制作队列及 `.timermix` 存档。
- 内置 300 杯基础酒谱与默认启用的 96 杯小董笔记 DLC。小董原稿、整理资料及已提供的私人配方随源码公开；推测补全与原始记录独立。
- 图文首页、使用指南、架构说明、MIT 许可证与 Fork/分支/PR 贡献指南。
- 项目方向是把 AI、营养数据、确定性计算和人类味觉反馈结合起来探索食谱。目前实现的是调酒规则候选与受控本地模型适配，完整营养优化与实饮校准仍待研究。
- 保留原应用 ID、数据库目录、内部可执行文件名和存档兼容。安装器沿用当前用户目录，不合并工作区预览与安装版的私人资料库。

Windows x64 下载 `Programmer_Mixology_Setup_1.2.0_x64.exe`，校验见 `SHA256SUMS.txt`。该安装器未签名，需要已有 WebView2，无需模型即可使用经典模式。


新用户、安装器与 README 默认英文，设置中仍可切换中文，已有有效语言选择继续保留。中文说明使用完整翻译的中文架构图。
