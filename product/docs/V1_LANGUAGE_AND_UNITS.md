# TIMER V1.0：语言、单位与存档

设置 → 常规的语言选项可立即切换中文 / English，保存到当前本机资料。主工作台、设置、队列和两个独立配料/杯图浮窗使用同一语言。设置最后的「关于 / About」显示 V1.0、UNKNOWNTIMER，以及 https://github.com/UNKNOWNTIMER。切换语言不改变配方、五味目标、票据、订单快照或任何来源数据；未知个人配方和自由文本保留原文。

300 杯内置酒谱的英文步骤为独立展示资源。社区来源优先使用此前留存的英文原文；其余步骤依据当前中文整理翻译。资源以内容签名和来源 URL 核对，已修改的配方不会仅因为 ID 相同而套入旧翻译。这些文字不会回写资料库。

## 国际单位显示

- 容量优先 ml，质量优先 g：已知 cl/dl/l、kg/mg 等按单位定义换算；明确的美制/英制液量盎司分别处理。
- 来源仅写 oz、tsp、tbsp、cup 时，显示使用美制容量约定，并加 `≈`。例如液体 1 oz 显示约 29.57 ml，1 tsp 约 4.93 ml，1 tbsp 约 14.79 ml。展开详情中的「原量与单位换算」可看到原量和约定；原始字段不变。
- 非液体的含糊 oz 不推断为体积；未标容量的 shot、barspoon、dash、part、少量、加满、叶片和装饰不编造 ml。未提供密度的粉末不把容量换成质量。
- 数量区间两端分别缩放，不取中值冒充确定量。多份展示乘以份数，原量仍可追溯。
- 成杯、酒精度和热量估量采用已知液体的换算体积，明确标出美制容量约定；未明剂量仍使完整估量保持未知。原料类别、糖分、融水等仍是编辑估算范围，不是品牌营养测量。

换算依据：[NIST SP 811 Appendix B.8](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors/nist-guide-si-appendix-b8)。`quantity-display.ts` 只提供展示和估量值，禁止将其写回权威配方或订单。

## 存档与队列

拖出 TIMER 标签生成 `中文酒名_english_drink_name.timermix`，例如 `蓝色飓风_blue_hurricane.timermix`。文件名不含UUID，英文转小写、词间用下划线连接，始终包含已有的两种名字且不随界面语言改变；保留重音字符，清理 Windows 禁用字符，超长自定义名共用80个 UTF-16 单元预算（分隔符另计）。独立缓存目录和文件内容保留内部UUID，重复导出不覆盖前次快照。每杯酒根据配方内容生成杯型、液面、颜色和纹理不同的像素图标，图标放在存档文件本身，不依赖同目录旁路文件。颜色和纹理是艺术表达，不是实际酒液测量。

同一文件可以反复拖入，每次生成独立队列条目。首杯自动载入，后续追加；点首杯 × 自动读取下一杯，点后续项 × 仅取消该项。源存档不删除，票据不扣除；完整队列最多 20 杯，工作台状态超过容量时明确拒绝。

旧 `.pixelmix` 以及符合存档格式的 `.json` 仍能读取，无须批量改名；旧纯 JSON 存档没有内嵌图标，可重新拖出生成带杯型图标的 `.timermix` 文件。图标关联只注册当前用户，不接管其他应用的关联，也不添加双击打开命令。

桌面 TIMER 快捷方式的图标由用户原始大图重建为 16/24/32/48/64/96/128/256 八种尺寸；内容哈希路径避免继续使用旧 32px 文件。快捷方式仍启动开发预览，数据保存在独立 `.local-preview/`，本轮没有新安装器。
