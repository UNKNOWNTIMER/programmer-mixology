# 小董调酒笔记 DLC

在经典酒谱库的“自定义”页打开“小董调酒笔记”。它随应用提供，默认启用，点击组开关即可让整组退出或重新进入工作台。组内仍可逐杯复制添加、隐藏、删除及恢复。关闭组不修改已经导出的文件、历史快照或独立个人副本。

用户提供的《TIMER_调酒笔记_详细清单与酒语.docx》共97条记录。本次整理为96杯饮品工作配方，另1条“酒鬼话梅小菠萝”保留于组内笔记附录。原作者为小董。97条并不是97份经过实际试调的完整标准配方：其中包含品饮体验、仅有名称、构想、试验和未执行计划。

## 笔记与补全

- 原文名称、材料、明确剂量、疑项、体验、酒语和文学背景保留。正文不足的16条另拟建议配方，未声称复刻原酒吧；其余保留原有材料与数字，补充工作单位、加满量、方法与杯型。额外材料和分支选择有独立备注。
- 份量、五味、七维和营养是本次AI辅助编辑的预测与计算。五味用最大余数法归一成10000整数基点，七维分别受酒液结构、香气、浓稠、碳酸、冷制、辛辣和余味规则影响。原文星号不写入实饮评分。
- 新原料的ABV、密度和热量等实际标签继续保留未知；界面另显示有明确范围的类别估算。身份未明的 `telska`、预调液等没有被擅自认定为某个品牌。估算范围不代表产品保证值。
- 咖啡奶酒澄清建议版单独计算过滤损耗；保留源大剂量的酒没有被静默缩小。冷制步骤不执行文档里的非食品或点火内容。原文完整副本仍保留供核对。
- 所有工作版仍需试调与实际瓶标核对，默认不可供客人点单。模型或笔记预测不能授予菜单权限、决定扣票或充当真实评价。

在左侧配料窗可查看“小董的笔记”、展开“笔记故事”和“工作配方记录”；点击杯图显示该记录的原酒语。文学内容保留中文原文，切换英文界面不会把新译文假称为作者原话。

## 画像与存档

96杯均有根据工作杯型、酒液颜色、泡沫、冰与装饰绘制的彩色ASCII画像和逐杯像素图标，图像属于艺术示意。图标包含16、24、32、48、64、128、256像素尺寸，嵌入单个 `.timermix` 文件。文件名仍采用 `中文名_english_name.timermix`。

将左下TIMER标签拖出可保存当前配方。打开经典酒谱库后拖回文件，即添加独立个人配方并跳到“自定义”；正常工作台拖回仍进入制作队列。同一文件可重复添加。导入会保存完整来源快照，保留作者、酒语、故事、剂量、步骤和预测；不会把存档目标写成配方预测。相同内容换个人ID后依然识别专属画像；编辑其核心配方后按新的配料结构绘图。
