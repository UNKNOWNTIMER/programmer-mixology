# 本轮开发预览

双击桌面 **TIMER调酒台** 快捷方式，或 `product/Start-Preview.cmd`，运行真实 Tauri 开发二进制。窗口固定 675×960，顶部居中 TIMER调酒台。本轮遵照“不着急打包”，未生成或替换安装包。

数据库与WebView资料保存在 `product/.local-preview/`；真实安装版个人数据不变，预览也不使用测试账户/库存。不要直接双击 `target/debug/pixel-mix.exe` 绕过入口，否则会采用Tauri默认个人数据目录。重建先关闭开发预览：

```powershell
. .\product\scripts\enter-build-env.ps1
pnpm --dir product/apps/client build
cargo +stable build --locked --manifest-path product/Cargo.toml -p pixel-mix
. .\product\scripts\start-preview.ps1
```

## 操作

- 酒名/列表图标进入 **300 份酒谱库**；爱心收藏。选择酒谱保留当前目标；灰色经典刻度中的具体配方会一次载入五味、七维与酒谱。来源页显示版本和原始资料分歧的审查说明。
- 配料区悬停在主窗口左侧打开独立原生窗口，点击配料区或菜单图钉固定；内含步骤、原始单位/范围、份数及成杯/ABV/热量估量，依据在折叠说明中。鼠标移入菜单可继续查看，Escape 关闭。主窗口固定无滚动，长详情只在菜单内滚动。
- 五味拖动/滚轮/键盘始终 10000 整数基点；**双击标签或滑杆锁定/解锁**，聚焦后 L 也可切换；回转箭头撤销。七维互相独立，折线连接真实位置；滚轮 0.5，Shift 滚轮 0.1。调整任一维度实时切换匹配酒谱，不用按匹配键，不会把先验写回目标。
- ASCII 红色节点支持悬停/键盘聚焦，换酒后分散随机；弹层显示配料、资料和味觉，先验/目标独立列出。点击杯体显示该杯的独立引语。300杯均有稳定的逐配方字符画像：8种杯型、10套配色，按来源呈现冰、装饰、泡沫等；颜色和纹理为艺术示意。底部 ↻ 随机会载入所选配方的完整先验，五味、七维及折线在约420ms内移动到对应数值；连续随机从当前画面续接，手动输入立即接管。“附近”限制到最近10种可选配方。
- 右下S/A/B/C/D是目标匹配等级，不是实饮评价。点击进入独立实饮记录。
- 设置可开启 AI 模式，未开启时匹配键灰色。先核对实际 SKU 再生成；未配置模型时明确回退规则。最近4份结果在“本机草稿→最近试调”恢复；不会自动成为客人菜单。默认文字125%、减少动态关闭、启动动画开启；已有显式保存的设置保留。启动使用提供的 TIMER LOGO，从可见绘制后显示约400ms并由马赛克变清晰，七区随机从外侧淡入；各模块680ms、错峰最多210ms，全部结束后进入可操作状态。软件内「减少动态效果」控制本软件启动、滑块及标签动画，Windows关闭动画不会强行覆盖本软件设置；可随时在软件中关闭动画。
- 票据区↗管理账户和局域网。主机审核菜单、有效客人账户和有效票均满足时Logo才亮；失败保留原请求，重试不重复扣票。确认后旋转变暗。主管理员邮票点击/Enter/拖开35%只读快照，不会自动接单。
- 按住 TIMER LOGO 移动超过8px会创建 `.timermix` 存档并进入 Windows 文件拖放；短按保留原点单行为。存档包含当前配方、原先验与独立目标，拖回可恢复个人快照，不能恢复票据/权限或上架菜单。当前用户只注册文件图标，双击文件并不启动导入。真实 Explorer 拖出/拖回尚未完成物理交互验收；详细证据与限制见 `RECIPE_ARCHIVE.md`。

模型建议来自2026-09-21在TIMER实测的Ryzen9950X3D、61.61GiB内存、RX7900XTX：经审核的Qwen3-4B-Instruct-2507 GGUF Q4_K_M、4096上下文、先用8线程CPU；Vulkan需另测。**没有下载或安装模型**；启用要求授权及可信文件/版本/许可证/校验值。[Qwen官方模型页](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507)与[llama.cpp构建说明](https://github.com/ggml-org/llama.cpp/blob/master/docs/build.md)是配置参考，不是本机推理证据。
