# 自定义酒谱库（V1.0）

从酒名或左上角酒谱库图标进入“经典酒谱库”。管理功能使用桌面应用的 Rust / SQLite；浏览器预览仅可浏览，管理按钮明确禁用。

- **添加酒谱**：填写中文或英文酒名、配料和制作步骤。只填一种语言时，另一名称自动使用相同文字。支持剂量、范围、单位、杯型、调制方法、装饰与来源网址。
- **复制添加**：内置经典酒谱可复制为个人版本，原始来源配方不会被覆盖。
- **自定义 / 编辑**：修改已保存的个人版本，每次保存产生新的配方版本。味觉与七维是手动填写的配方预测；“使用当前味觉”才会复制当前工作台目标。
- **隐藏 / 显示**：隐藏的酒谱退出正常酒库列表、实时匹配、随机及滑杆经典预设；在“已隐藏”中重新显示。
- **删除 / 恢复**：删除前有应用内确认，之后移至“已删除”，可恢复。它不会从历史订单、实饮评价或已经导出的 `.timermix` 文件中删除配方快照。
- **小董调酒笔记 DLC**：在“自定义”内单独分组，默认已启用。点击组右侧“已启用”切换为“未启用”，组内酒谱退出工作台、匹配、随机与白色预设；再次点击恢复。组开关不删除配方，不重置逐杯隐藏／删除记录，也不会隐藏另外复制或导入的独立个人版本。
- **拖入酒谱文件**：打开经典酒谱库，将一个 `.timermix` 文件拖进主窗口，验证成功后切换到“自定义”，选中并高亮新副本。同一文件可以多次添加，每次都是独立可编辑的酒谱。正在编辑时须先保存或取消草稿；导入失败会显示原因，不会转而加入制作队列。没有打开酒谱库时，拖入保持原来的制作队列用途。

当没有可见酒谱时，工作台直接显示管理页，仍可添加或恢复。已隐藏、已删除和自定义的管理分类不受库存筛选影响，防止条目无法找回。原本已经审核并发布的主机菜单由主机单独管理，个人库操作不追溯修改订单或菜单版本。

新导出的酒谱文件统一使用 `.timermix`。以前的 `.pixelmix` 和符合完整存档格式的 `.json` 仍可按相同步骤读取，不需要改名；再次导出会生成新的 `.timermix`，保留原文件。

## 数据与边界

个人库独立存入 SQLite `settings.recipe_library`，包含版本、修订号、个人配方及可见性记录；300 杯源酒谱、原料标签、用户目标和评价不改写。重启自动读取，现有 SQLite 备份包含这份资料。保存使用修订号校验，冲突会刷新库并明确要求重试；失败不会返回成功、覆盖其他修订或丢弃编辑稿。保存期间阻止关闭编辑器和程序；异步生成和存档导入不会自动关掉正在编辑的酒谱库。

配料从已有目录中选择：255 项来源原料，加“政霖汤”的香草星云预制泡沫及小董笔记的48项新定义，共304项；原始来源表不改写。泡沫的15 ml指打发后体积，营养与密度未知，作为可选装饰使用。DLC中的身份不明或品牌未核对材料保留原备注；显示估算不写入实际标签。目前不提供新增原料类型的表单。个人库最多 100 杯（包括已删除的个人酒谱），整个个人库上限 256 KiB，达到任一上限会拒绝保存并显示错误。96杯只读DLC不占个人杯数或容量，但另行复制／导入的版本会占用；长文存档可能先达到容量上限。本版删除可恢复，尚无永久清空回收站操作。浏览器预览不能替代桌面 SQLite 管理验证。

新建配方的默认预测为五味各 20%、七维各 5 分。五味内部始终是合计 10000 的整数基点；预测不会冒充实饮评分或反向修改当前目标。所有个人酒谱都默认不可供客人点单，仍需既有主机审核与份量配置。来源网址只作为用户填写的资料保存，不自动抓取或声称核验。

导入时 `.timermix` 内完整的原配方、配料剂量、步骤、笔记、作者来源、预测和用户目标快照进入导入出处记录；活动个人版本使用原配方预测，不用目标替换预测。导入、编辑或关闭DLC都不改旧文件与原始来源。相同核心配方的画像和酒语可随新ID恢复；实质编辑材料／步骤后重新按新配方绘制，不强行附上原专属画像。来源库中未定义的原料不能绕过校验导入。

小董笔记详细说明见 `XIAODONG_DLC.md`；验证证据在 `evidence/xiaodong-dlc/`、`evidence/dlc-library/`，命令与实际结果见 `BUILD_REPORT.md` 最新章节。
