# 红点资料浮窗

2026-09-21：杯图的配料、资料、味觉红点使用独立 Windows 浮窗。浮窗附属于主窗，可越过主窗边界；没有单独任务栏项，不是全局置顶窗口。

- 悬停红点打开资料，沿延展线移入卡片时保持展开。点击红点或键盘聚焦可保持选中；关闭按钮、Escape、工作台其他位置点击和换酒收起卡片。
- 红蓝折线从红点引出，末端接到卡片靠近红点一侧的标题边缘。卡片和连线共用 Rust 返回的物理位置换算结果，空间不足时一起换侧。主窗移动时跟随，屏幕工作区限制卡片边界；混合 DPI 使用两窗的缩放比例换算标题连接点。
- 蓝色显示目标或剂量，红色显示配方先验或占比。用户目标、配方未验证先验和真实评价仍独立。2026-09-22按用户截图移除“原配方备注”“估量依据”“先验说明”三个解释折叠区；估量未知/范围、必要数量备注及源快照不改，来源仍可在配方详情中查看。
- Windows 使用 `glass-details` 原生窗口。浏览器和手机布局使用视口内浮层，不能越过浏览器/手机系统窗口；不宣称手机原生浮窗已验收。

窗口权限仅允许读取当前资料、确认显示尺寸、发送 enter/leave/close，以及订阅数据事件。主机、模型、存档、目录、工作台状态及任意事件发送均不可从资料窗调用。过期 token 不能重新打开上一次的卡片。

实际命令、测试结果、失败修复与实机边界见 `../BUILD_REPORT.md` 最新“红点独立浮窗”章节。专项脚本 `../tests/native-glass-callout.cjs` 限定隔离测试数据目录；左右布局覆盖中使用的测试专用坐标与自然截图分开记录。
